About nanopc t4 Bluetooth

Posted on August 4, 2026

Recently, I bought a FriendlyElect nanopc T4, and I found that the bluetooth function of the nanopc T4 is not working properly. I tried to connect a bluetooth headset to the nanopc T4, but it has very high latency.

I tried searching online for solutions, but nothing was found,after several hours of searching,ChatGPT gave me a solution, I tried it and it worked! Here is the solution:

I use the armbian,If you are using anothe system,please adapt the solution by yourself

First open a terminal and run the following command:

sudo armbian-config

Then select "System" and then "Kernel" and then select "Edit device tree" ,select "select and edit a device blob"and then select "nanopc-t4.dtb" and then select "Edit"

Then find the line that says:

                bluetooth {
                        compatible = "brcm,bcm43438-bt";
                        clocks = <0x4a 0x01>;
                        clock-names = "lpo";
                        device-wakeup-gpios = <0x1c 0x1a 0x00>;
                        host-wakeup-gpios = <0x2c 0x04 0x00>;
                        shutdown-gpios = <0x2c 0x09 0x00>;
                        max-speed = "", "=\t";
                        pinctrl-names = "default";
                        pinctrl-0 = <0x4b 0x4c 0x4d>;
                        vbat-supply = <0x1d>;
                        vddio-supply = <0x4e>;
                };
        };

And change max-speed = "", "=\t"; to max-speed = "3000000" and then save the file and exit the editor

Then reboot the system and try to connect your bluetooth device again, it should work properly

This is becaue bcm43438 can work up to 3Mbps, but the dts does'nt give the correct speed,if you can check the dmesg you will find the bcm43438 has a error message about the speed,so we need to change dts to config it properly
